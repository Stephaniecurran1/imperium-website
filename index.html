Digital Security

Client access is designed around secure authentication practices and account-session controls.

Account Security Features

  • Password Authentication Client accounts use password-based authentication.
  • One-Time Verification Additional verification can be required during sign-in.
  • Trusted Device Clients can choose whether a device should be recognised for future access.
  • Session Timeout Inactive sessions can automatically expire for security.
  • Sign Out Clients can securely end their current account session.
  • Secure Client Access Account functionality should be connected to a secure server-side authentication system before production use.
