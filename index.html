Digital Security

Client access uses modern authentication and database-access controls.

Security Features

  • Authentication Client accounts are authenticated through Supabase Auth.
  • Session Management Authenticated sessions are managed by Supabase.
  • Row Level Security Database access is restricted using Supabase RLS policies.
  • Sign Out Clients can securely terminate their active session.
  • Database Protection Private service-role credentials are not exposed in the website.
  • HTTPS The website should be served over HTTPS in production.
